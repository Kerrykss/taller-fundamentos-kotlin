# Taller de Fundamentos de Kotlin

## 👨‍💻 Información del Proyecto

**Autor:** Kerry Alejandro Herrera Garcia  
**Descripción:** Este proyecto contiene 40 ejercicios fundamentales de Kotlin organizados en 6 bloques temáticos.

## 📚 Contenido del Taller

El taller está organizado en los siguientes bloques:

### Bloque 1: Variables (Ejercicios 1-5)
- Declaración de variables inmutables (val)
- Declaración de variables mutables (var)
- Tipos de datos: String, Int, Double, Boolean
- Inferencia de tipos

### Bloque 2: Null Safety (Ejercicios 6-10)
- Variables nullable
- Operador safe call (?.)
- Elvis operator (?:)
- Not-null assertion (!!)
- Bloque let con nullable

### Bloque 3: Condicionales (Ejercicios 11-15)
- if-else simple
- if-else if-else múltiple
- when simple
- when con rangos
- when con verificación de tipos

### Bloque 4: Ciclos (Ejercicios 16-25)
- for con rangos
- for con rangos descendentes
- for con step
- for con iteradores
- while y do-while
- break y continue
- forEach y repeat

### Bloque 5: Funciones (Ejercicios 26-30)
- Funciones simples
- Funciones con parámetros
- Parámetros por defecto
- Parámetros nombrados
- Parámetros variables (varargs)

### Bloque 6: Colecciones (Ejercicios 31-40)
- List inmutable
- MutableList
- Acceso a elementos
- Set
- Map (diccionario)
- filter
- map (transformación)
- any y all
- find y firstOrNull
- groupBy

## 🚀 Cómo Ejecutar el Proyecto

### Requisitos Previos
- JDK 17 o superior instalado
- IntelliJ IDEA (o cualquier IDE compatible con Kotlin)

### Pasos para Ejecutar

1. **Clonar el repositorio:**
   ```bash
   git clone https://github.com/tu-usuario/taller-fundamentos-kotlin.git
   cd taller-fundamentos-kotlin
   ```

2. **Abrir en IntelliJ IDEA:**
   - File → Open
   - Selecciona la carpeta del proyecto
   - Espera a que se indexe

3. **Ejecutar el programa:**
   - Haz clic derecho en `Main.kt`
   - Selecciona "Run 'MainKt'"
   - O presiona Shift + F10

4. **Ver los resultados:**
   - Los resultados de todos los 40 ejercicios se mostrarán en la consola
